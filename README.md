# Search Relevance & Content Quality Evaluation

**Connor James Young | Independent practice project | Completed**

## Purpose

Practise identifying search intent, assessing webpage relevance and credibility, and documenting evidence-based judgements consistently.

**Current state:** This repository contains a completed project with documented search queries, scores, results, observations, and findings.

## Project Scope

- 5 queries covering troubleshooting, local information, shopping, factual explanations and entertainment.
- The first three ordinary, non-sponsored webpage results per query: up to 15 evaluations.
- A custom four-part rubric, with a written justification and verification evidence for each result.
- A short findings report and a consistency review of selected ratings.

## Method overview

State the user's likely intent before opening results. Record the search date and context, then open and evaluate each selected page. Use the same rubric throughout, document supporting evidence and acknowledge uncertainties.

## Independence and limitations

This is an independent learning exercise. Its 10-point rubric is custom and does not represent an employer's assessment system. It makes no claim of professional rating experience.

Search results can vary by location, time, device and personalisation. A small, single-reviewer sample cannot establish the overall quality of a search engine. Relevance, credibility and factual accuracy are related but distinct.
