# Search Relevance & Content Quality Evaluation

**Connor James Young | Independent practice project | In progress**

## Purpose

Practise identifying search intent, assessing webpage relevance and credibility, and documenting evidence-based judgements consistently.

**Current state:** This repository contains a project plan and blank evaluation templates. No search results have been assessed yet. Suggested queries and result positions are planned work, not observations.

## Planned scope

- 20 queries covering troubleshooting, local information, shopping, factual explanations and entertainment.
- The first three ordinary, non-sponsored webpage results per query: up to 60 evaluations.
- A custom four-part rubric, with a written justification and verification evidence for each result.
- A short findings report and a consistency review of selected ratings.

The query list is provisional. Record any substitutions and the reason in the findings report. If fewer evaluations are completed, report the actual count.

## Method overview

State the user's likely intent before opening results. Record the search date and context, then open and evaluate each selected page. Use the same rubric throughout, document supporting evidence and acknowledge uncertainties. See [methodology.md](methodology.md) for full instructions.

## Independence and limitations

This is an independent learning exercise, not a Welo Data or Google assignment. Its 10-point rubric is custom and does not represent an employer's assessment system. It makes no claim of professional rating experience.

Search results can vary by location, time, device and personalisation. A small, single-reviewer sample cannot establish the overall quality of a search engine. Relevance, credibility and factual accuracy are related but distinct.
